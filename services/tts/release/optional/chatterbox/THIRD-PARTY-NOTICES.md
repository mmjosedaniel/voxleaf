# VoxLeaf optional Chatterbox package notices

This directory is the release authority for the separately acquired optional
Chatterbox profile. A downloadable package must include this notice together
with the exact runtime lock, source manifest, model provenance, the licence
texts discovered from the synchronised locked environment, and the licences
for Chatterbox, the model/default conditioning, and PerTh.

The profile is not part of the Piper core. Schema v1 remains historical. No
files under this directory are an end-user download until
`optional-package-manifest-v2.json` is changed from `withheld` to a complete,
integrity-pinned multi-artifact authority after the runtime parts are published
and the clean-host, audit, licence, offline-use, and removal gates pass.

Schema v2 downloads exactly six model-data files from the frozen official
`ResembleAI/chatterbox` Hugging Face revision. It never executes model-
repository code. The separately built runtime-only payload includes the exact
locked Python graph and the licence/source material collected by the builder.
