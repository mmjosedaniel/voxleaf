## Testing and benchmark strategy

All validation runs in normal local PowerShell outside the managed sandbox.
Start with existing focused scripts (`lint:typescript`, `typecheck:typescript`,
`@voxleaf/shared generate:check`, package tests). Final gates are `pnpm.cmd check`,
`pnpm.cmd test:browser`, `pnpm.cmd test:native-startup`,
`pnpm.cmd inventory:release:check` and `pnpm.cmd audit:release`. Install the browser
matching Playwright through `pnpm.cmd test:browser:install`. Native smoke uses
actual WebView2 with a supervised fake service, not model/GPU inference evidence.
Compare production bundle output when build-tool changes affect it. The testing
guide requires reader remeasurement after changing Chromium: run
`pnpm.cmd benchmark:reader` and `pnpm.cmd benchmark:reader:native` sequentially on
the Windows reference host, retaining their existing limits.

## Risks and rollback

Major compiler/test-runner/DOM-emulator changes can reject supported code or alter
test semantics. Retain the supported previous version when an ecosystem upgrade
cannot pass without weakening guarantees. Reverting the scoped preparation and
dependency commits restores the previous graph; preserve all original PR history.
