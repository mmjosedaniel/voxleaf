## Product findings

- [VF-0133](../registry.md#vf-0133) **P2 · A cancelled Download can borrow the next confirmation.** On a compatible host, a scheduling delay before native confirmation capture can span Cancel and a fresh Review. The renderer releases the earlier pending Download when Cancel returns Absent. Native capture takes the current confirmation, so the old command can start a transfer before the new Download click. U8/2.1 covers cancellation after token capture. For a follow-up, hold the first command before capture, verify zero transfer requests after the second Review, and keep the genuine second Download and in-progress Cancel controls. [Renderer](../../../../apps/desktop/src/tts/optional-chatterbox-client.ts#L309) · [Native handoff](../../../../apps/desktop/src-tauri/src/tts_optional_chatterbox.rs#L2793) · [Existing post-capture fixture](../../../../apps/desktop/src-tauri/src/tts_optional_chatterbox/tests.rs#L448)
- [VF-0134](../registry.md#vf-0134) **P2 · A valid chapter filename can prevent EPUB opening.** A root-level filename beginning with U+00A0 survives archive intake and a percent-encoded manifest reference. The projection leaves the decoded whitespace in a field whose schema rejects it. Check opening through the public API with this filename, while preserving real archive lookups, stable locations, the `#` alias and collision avoidance. [OCF decoding](../../../../packages/epub/src/paths/ocf-reference.ts#L119) · [Projection](../../../../packages/epub/src/book/book-v1-projection.ts#L119) · [Schema](../../../../packages/shared/schemas/book/v1.schema.json#L106) · [EPUB filename rules](https://www.w3.org/TR/epub-33/#sec-container-filenames)
- [VF-0135](../registry.md#vf-0135) **P2 · An internal link wrapping a paragraph can prevent EPUB opening.** The valid link enters an inline collector and the supported paragraph requires a block collector. The projector fails the whole publication. Compare public opening for a block-wrapping local anchor, a normal inline link and the previously fixed inert wrapper. Preserve safe descendants and the existing link policy. [Collector](../../../../packages/epub/src/document/xhtml-projector.ts#L1321) · [Guard](../../../../packages/epub/src/document/xhtml-projector.ts#L1609) · [HTML anchor content model](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-a-element)
- [VF-0093](../registry.md#vf-0093) **P2 · Cancel start can still time out during Piper verification.** Current native code retires the pending start before spawn. The typed client still awaits the startup promise after its exact cancellation receipt, and the coordinator also joins it within five seconds.
