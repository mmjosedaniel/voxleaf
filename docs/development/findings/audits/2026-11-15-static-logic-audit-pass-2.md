### VF-0063 — Keyboard recovery

Consider a settled unavailable placement with Play disabled, reader content focused, a readable viewport and upward scroll room. The [keydown handler](../../../../apps/desktop/src/reader/ReaderPublication.tsx#L1341) rejects `shiftKey` before calling `recordManualScrollIntent`. Chromium's default Space handler uses Shift to reverse page scrolling, so a trusted chord can move the reader without arming that intent. With no earlier intent, [the scroll tracker](../../../../apps/desktop/src/reader/active-visual-locator.ts#L429) produces no measured-manual event. A passive sample can still update the visible locator. [Narration](../../../../apps/desktop/src/tts/product-narration-coordinator.ts#L909) needs the measured-manual flag to lift that gate. [Blink default Space handler](https://chromium.googlesource.com/chromium/src/+/e723fd7cc353b569dbcf371b3d361eb4199a122e/third_party/blink/renderer/core/input/keyboard_event_manager.cc#372), [Edge keyboard reference](https://support.microsoft.com/en-us/edge/keyboard-shortcuts-in-microsoft-edge).

The existing keyboard control reaches the article through the skip link and presses unmodified PageDown. The gesture reaches a different branch from VF-0034's scrollbar route. A follow-up should observe a real scroll and the first prepared locator in WebView2, with no preceding intent. Compare PageUp, control activation and programmatic scroll. The host occurrence was not observed in this pass. [Existing wheel and PageDown controls](../../../../apps/desktop/tests/browser/reader-narration-bugfixes.smoke.spec.ts#L5290), [VF-0034](../registry.md#vf-0034).

### VF-0064 — Direction on generated paragraphs

For an LTR XHTML body with direct text inside `<div dir="rtl">`, the block-boundary handler records the `div` frame and continues using the enclosing body collector. The text node takes the frame's RTL context. The implicit paragraph gets LTR from the collector. [Block-boundary handler](../../../../packages/epub/src/document/xhtml-projector.ts#L947), [text node](../../../../packages/epub/src/document/xhtml-projector.ts#L1013), [implicit paragraph](../../../../packages/epub/src/document/xhtml-projector.ts#L1392).

The renderer puts the two contexts on different elements. The paragraph's direction determines the sampling edge and can affect mixed-direction layout. An explicit `p` under the same `div` takes its own effective RTL context. [Paragraph rendering](../../../../apps/desktop/src/reader/SemanticDocument.tsx#L546), [inline text rendering](../../../../apps/desktop/src/reader/SemanticDocument.tsx#L223), [sampling edge](../../../../apps/desktop/src/reader/active-visual-locator.ts#L662), [direction contract](../../../architecture/decisions/ADR-0008-visual-reader-architecture.md#render-closed-semantic-values-directly-in-the-application-dom).

M003 admits direct inline runs in these containers. The existing [projection](../../../../packages/epub/src/document/xhtml-projector.test.ts#L371) and [rendering](../../../../apps/desktop/src/reader/SemanticDocument.test.tsx#L407) context fixtures cover chapter inheritance and explicit semantic direction. Compare the implicit and explicit paragraph through public opening and the mapped caret under equivalent layout.

### VF-0065 — v14 derivation order

The [official runner](../../../../services/tts/benchmarks/batch_cli.py#L314) publishes two ignored evidence files and then reports `eligibleForDerivation`. The [derive command](../../../../services/tts/benchmarks/batch_result_cli.py#L100) reads both in a `try` and deletes the exact session in `finally`. It validates and constructs the summary afterward. For example, a local schema digest mismatch at [v14 authority validation](../../../../services/tts/benchmarks/v14_authority.py#L145) raises after the evidence has been removed. An input read error also takes the cleanup path. Correcting the local authority or read condition cannot make the same session retryable. The raw evidence is already documented as content-free and waveform-free. [Official workflow](../../../../benchmarks/tts/README.md#L581), [raw and summary validation](../../../../services/tts/benchmarks/batch_result.py#L164).

The [routing test](../../../../services/tts/tests/test_benchmark_batch_cli.py#L228) requires early absence while substituting the actual validator. The [v5 command](../../../../services/tts/benchmarks/dual_worker_result_cli.py#L51) validates before cleanup and publishes only after verified removal. VF-0065 concerns the current v14 route. The earlier [VF-0024](../registry.md#vf-0024) concerns retry after partial cleanup of a v12 finalization. Use disposable synthetic evidence to distinguish authority rejection and successful cleanup on retry. There is no current v14 hardware result from this audit.
